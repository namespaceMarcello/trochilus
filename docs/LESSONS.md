# Lessons

Every error and discovery, as soon as it happens. A lesson is **closed** only when its
prevention is automatic: a test, a check in `make check`, a pin, a hook. A phrase
in a document is weak prevention and is declared as such (column «Prevention»: *rule*).

«Found by» measures the success rate: the goal is that no error reaches Marcello
when a test could have found it first. When it does, the prevention must be a check.

Appended at the tail. A lesson that is superseded is corrected on its own line, not written
alongside a new one.
